# Установка «Участков» на Android

APK рассчитан на Android 7.0 и новее с 64-битным процессором ARM (ARM64).

1. Откройте [страницу скачивания](https://github.com/hunter-x-unicorn/uchastki/releases/latest).
2. Скачайте `uchastki-1.0.1.apk` и откройте файл на телефоне.
3. Если Android запросит, разрешите установку приложения для браузера, через который скачали файл.
4. Если «Участки» уже установлены, выберите «Обновить»: не удаляйте прежнее приложение. APK подписан тем же ключом, что версия 1.0.0.
5. Для дальнейших совместимых обновлений достаточно открывать «Участки» с интернетом и соглашаться на обновление в появившемся окне.

Для обхода интернет не нужен. Новая синяя иконка на рабочем столе появится после установки этого APK. Изменения интерфейса также приходят в старый APK через автоматическое обновление.
