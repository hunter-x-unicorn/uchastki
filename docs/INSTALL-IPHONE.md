# Установка «Участков» на iPhone бесплатно

Требуется iPhone с **iOS 16.4 или новее**. Для установки без App Store нужен компьютер Windows или Mac, кабель и бесплатный Apple Account.

1. На компьютере откройте [страницу скачивания](https://github.com/hunter-x-unicorn/uchastki/releases/latest) и скачайте `uchastki-1.0.1-unsigned.ipa`.
2. Установите [Sideloadly с официального сайта](https://sideloadly.io/). При работе с Windows следуйте его инструкции по необходимым компонентам Apple.
3. Подключите iPhone к компьютеру и подтвердите «Доверять этому компьютеру» на телефоне.
4. Откройте Sideloadly, выберите iPhone и перетащите IPA в окно программы. Введите свой Apple Account в Sideloadly, нажмите Start и подтвердите вход Apple, если потребуется.
5. На iPhone подтвердите доверие профилю разработчика в «Настройки → Основные → VPN и управление устройством». Если iOS запросит режим разработчика, включите его в «Настройки → Конфиденциальность и безопасность → Режим разработчика» и выполните указания системы.
6. Откройте «Участки». Для совместимых обновлений включите интернет: приложение предложит применить новую версию.

**Ограничение бесплатного Apple Account:** подпись приложения действует 7 дней. Включите автоматическое продление в Sideloadly. Для продления компьютер должен работать, а телефон быть доступен по кабелю или настроенному Wi-Fi. OTA-обновления «Участков» не продлевают подпись Apple.

IPA намеренно не подписан чужим сертификатом. Скачивание его в Safari само приложение не установит. Для первоначальной установки нужен компьютер; оплачивать аккаунт разработчика не требуется. Физическая установка на вашем iPhone пока не проверена.

Сохраняйте резервную копию через меню приложения перед переустановкой или изменением Apple Account/идентификатора приложения. Пароли и коды Apple вводите только в соответствующих программах, не отправляйте их другим людям.

Основания: [Sideloadly](https://sideloadly.io/), [возможности бесплатного аккаунта Apple](https://developer.apple.com/help/account/basics/about-your-developer-account).
