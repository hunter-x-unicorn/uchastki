# Участки

Простое автономное приложение для Android и iPhone на React Native + Expo + TypeScript.
Собственный сервер и публикация в магазинах не нужны. Никаких платных библиотек.

## Возможности

- Участки с названием и необязательным адресом/описанием.
- Подъезды внутри участка; в названии подъезда можно указать дом.
- Автоматическое создание квартир по этажам: первый этаж, количество этажей, квартир на этаже и первый номер.
- Добавление отдельных квартир, произвольные номера с буквами, редактирование этажа.
- Статусы: «Не посещена», «Пройдена», «Никого не застали».
- Быстрые отметки с карточки и подробная карточка с заметкой.
- Поиск по номеру/заметке, фильтр статусов, порядок этажей, статистика.
- Автоматическое локальное сохранение. Для обхода интернет не требуется.
- Экспорт и восстановление JSON-копии для переноса между устройствами.
- Проверка файла перед восстановлением и подтверждение замены данных.
- Подключён проект Expo Update для совместимых обновлений.

Облачной синхронизации нет: на каждом телефоне своя копия журнала. При удалении приложения
локальные данные могут быть потеряны; сохраняйте копию через настройки.

## Что действительно бесплатно и какие есть ограничения

1. **Android:** установить один раз APK. Бесплатный Expo Build собирает APK с Windows и управляет подписью.
2. **iPhone:** собрать **неподписанный IPA** на облачном Mac, затем подписать/установить через Sideloadly с бесплатным Apple Account.
3. **Обновления:** бесплатный Expo Update доставляет JS-код и изображения. Нужен бесплатный аккаунт Expo и привязка проекта **до создания первой установленной сборки**.
4. **Подпись iPhone:** бесплатная подпись действует **7 дней**. Sideloadly может продлевать её через доступный компьютер по USB или настроенному Wi-Fi. OTA-обновления срок подписи не продлевают.
5. **Нативные изменения:** добавление нативных зависимостей, разрешений и обновление Expo SDK требуют новой сборки и установки APK/IPA.

Не используйте EAS/Expo Build для бесплатной iOS-установки: обычная сборка для физического
iPhone в этом сервисе требует платного аккаунта Apple. В этом проекте для iOS предусмотрена
отдельная **unsigned**-сборка на GitHub Actions или Codemagic.

Проверенные 17.11.2026 бесплатные лимиты:

- Expo Free: 15 Android- и 15 iOS-сборок в месяц, обновления для 1 000 активных пользователей в месяц.
- GitHub Actions: стандартные macOS runners бесплатны в публичном репозитории.
- Codemagic: индивидуальный бесплатный аккаунт, 500 минут macOS M2 в месяц; можно подключить закрытый репозиторий.

Платные тарифы не подключайте. Облачные сервисы требуют своих бесплатных учётных записей.
Для облачных сборок используются только аккаунты владельца проекта.
Репозиторий приложения: [hunter-x-unicorn/uchastki](https://github.com/hunter-x-unicorn/uchastki).

## Локально посмотреть приложение на Windows

Нужен Node.js 24 и npm.

```powershell
npm ci
npm run export:web
npm run preview
```

Откройте `http://127.0.0.1:8081`. Это локальное средство проверки интерфейса без размещения
сайта. Оно не заменяет устанавливаемые Android/iOS-сборки. Удобно включить размер экрана телефона.
Кнопка «Открыть учебный пример» добавляет явно помеченные учебные данные только в пустой журнал.

## Бесплатные обновления Expo

Проект уже связан с `andrey8636s-team/uchastki`, ID
`ff77991a-0072-4b8f-a524-01ce7bddf204`. Эти публичные настройки находятся в `app.json`;
создавать `.env.local` для текущего приложения не требуется.

1. Войти через CLI на компьютере владельца:

```powershell
npx eas-cli@27.10.0 login
```

2. Собирать APK и IPA с этими настройками. Установить их на телефоны.
3. Для публикации совместимых изменений:

```powershell
npm run update:publish -- --message "Исправлены формы квартир"
```

Сборки получают канал `production`. Приложение проверяет обновления при запуске и показывает
приглашение перезапустить его после загрузки. Перед перезапуском ожидается завершение сохранения.
Без Project ID обновления явно отключены, а весь журнал работает автономно.
Для собственного форка можно переопределить Project ID и владельца через `.env.local`
по образцу `.env.example`.

Версия нативного runtime соответствует `version` в `app.json`. При изменении нативных модулей,
разрешений или Expo SDK **сначала увеличить `version` и создать новые APK/IPA**. Не публиковать
несовместимое обновление в старый runtime. Для изменений только экранов/логики версию runtime сохранять.

## Собрать Android APK бесплатно

Если на компьютере установлен Android Studio, можно собрать APK локально без аккаунта Expo:

```powershell
$env:JAVA_HOME = 'ПУТЬ_К_ANDROID_STUDIO\jbr'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
npm run build:android:local
```

Готовый файл: `artifacts/uchastki-android-arm64.apk` (современные Android-телефоны ARM64).
Скрипт автоматически создаёт собственный ключ подписи в `.credentials/`, генерирует нативный
проект через Expo и собирает автономный release APK. **Сохраните всю папку `.credentials/`
отдельно:** без исходного ключа следующие APK не смогут обновить уже установленное приложение.
Папка с ключом исключена из Git и не публикуется. Сборка без Expo Project ID работает
автономно; для подключения OTA понадобится один раз установить сборку с Project ID.

Вариант облачной сборки без установленного Android Studio:

После настройки бесплатного проекта Expo:

```powershell
npx eas-cli@27.10.0 build --platform android --profile preview
```

Первый запуск интерактивный: выбрать создание Android keystore в Expo. Сохранить доступ к
аккаунту и резервную копию ключа подписи. Последующие APK должны быть подписаны тем же ключом,
чтобы устанавливаться поверх старых с сохранением данных.

Готовый APK скачивается со страницы сборки. На телефоне разрешить установку из выбранного
источника и открыть APK. Не требуется ни Google Play, ни платная учётная запись.
Изменения JS в дальнейшем доставляются через Expo Update.

## Собрать iPhone IPA бесплатно, без Mac и платного Apple Developer

### Вариант A: GitHub Actions

1. Открыть [репозиторий приложения](https://github.com/hunter-x-unicorn/uchastki).
   Исходный код опубликован; личные копии журнала и ключи подписи в репозиторий не входят.
2. Actions → **Build unsigned iPhone IPA (free)** → Run workflow.
   Изменения настроек нативной сборки в `main` также запускают сборку автоматически.
3. Скачать артефакт `uchastki-ios-unsigned`, извлечь `uchastki-unsigned.ipa` из ZIP.

Workflow использует настройки Expo из `app.json`. Переменные Actions `EAS_PROJECT_ID`
и `EXPO_OWNER` нужны только для явного переопределения проекта.

Задание намеренно пропускается в закрытом репозитории, чтобы не использовать платные macOS-минуты.
Исходный workflow — `.github/workflows/ios-free.yml`. Подпись Apple и отправка в App Store отсутствуют.

### Вариант B: Codemagic для закрытого кода

Подключить Git-репозиторий к индивидуальному бесплатному аккаунту [Codemagic](https://codemagic.io).
Выбрать конфигурацию из `codemagic.yaml`, workflow `ios-unsigned`.
При необходимости задать `EXPO_PUBLIC_EAS_PROJECT_ID` и `EXPO_OWNER` в переменных окружения.
Запустить сборку и скачать `uchastki-unsigned.ipa` из артефактов, оставаясь в бесплатной квоте.
Apple Developer Portal к этому заданию подключать не нужно.

### Установить IPA через Sideloadly

1. Скачать [Sideloadly](https://sideloadly.io/) для Windows или macOS.
2. На Windows установить указанные в его инструкции компоненты Apple для подключения телефона.
3. Подключить iPhone по USB, разблокировать его и подтвердить доверие к компьютеру вручную.
4. Перетащить `uchastki-unsigned.ipa` в Sideloadly, выбрать устройство и собственный Apple Account.
5. Выполнить подпись и установку. Apple ID и пароль не передавать разработчику или в GitHub.
6. На iPhone вручную подтвердить профиль разработчика, а на поддерживаемых версиях iOS включить Developer Mode.
7. Включить Automatic Refresh в Sideloadly. Держать компьютер доступным для переподписи хотя бы раз в 7 дней.

Для обновления полного IPA использовать прежний Apple Account и тот же Bundle ID,
устанавливая поверх существующего приложения. Перед переподписью/переустановкой лучше сохранить
резервную копию через настройки приложения. Не удалять приложение для обычного обновления.

Sideloadly не освобождает от недельной переподписи бесплатного аккаунта.
Полностью бессрочной бесплатной установки на произвольный современный iPhone здесь нет.

## Публикация обновлений через GitHub

В репозиторий можно добавить секрет `EXPO_TOKEN` (токен своего Expo-аккаунта) и переменные
`EAS_PROJECT_ID`, `EXPO_OWNER` при переопределении проекта, затем вручную запускать workflow **Publish compatible app update (Expo Free)**.
Токен не добавлять в исходный код. Задание проверяет код перед публикацией.

## Проверки и структура

```powershell
npm run lint
npm run typecheck
npm test
npm run export:web
npx playwright install chromium
npm run test:e2e
```

- `src/app/` — маршруты Expo Router; `App.tsx` — интерфейс журнала, сохранение и обновления.
- `src/model.ts` — модель данных, генерация квартир и строгая проверка копий.
- `src/storage.ts` — последовательная очередь локальных записей.
- `src/backup.ts` — обмен файлами через системный выбор документов и «Поделиться».
- `src/EntityEditor.tsx`, `src/ui.tsx` — формы, компоненты и оформление.
- `scripts/build-ios-unsigned.sh` — сборка и упаковка unsigned IPA на macOS.
- `tests/` — логика нумерации/данных и пользовательские сценарии в локальном интерфейсе.

Локальные проверки браузера не заменяют тестирование на реальных Android/iPhone. Нативная
компиляция iOS выполняется только на облачном Mac после подключения аккаунта владельца.
